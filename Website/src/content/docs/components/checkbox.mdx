## Use it

```swift compile
import Swift95
import SwiftUI

struct Checkbox95Example: View {
  @State private var showsHiddenFiles = true
  @State private var confirmsDeletion = false

  var body: some View {
    VStack(alignment: .leading, spacing: 6) {
      Checkbox95("Show hidden files", isOn: $showsHiddenFiles)
      Checkbox95("Confirm before deleting", isOn: $confirmsDeletion)
      Checkbox95("Unavailable option", isOn: .constant(true))
        .disabled(true)
    }
  }
}
```

## Essential behavior

| Concern | Behavior |
| --- | --- |
| Binding | Reads and writes a `Binding<Bool>`. |
| Semantics | Preserves native toggle behavior, enabled state, keyboard use, and accessibility. |
| Custom labels | Use `Checkbox95(isOn:label:)` for composed SwiftUI labels. |
| Native APIs | Use `swiftUI(_:)` to modify the embedded `Toggle`. |
