`Menu95` groups
[`MenuItem95`](/api/documentation/swift95/menuitem95) commands and
[`MenuDivider95`](/api/documentation/swift95/menudivider95) separators in a
workspace window menu bar.

## Use it

```swift compile
import Swift95
import SwiftUI

struct Menu95Example {
  @MainActor
  static func makeWindow() -> WorkspaceWindow95 {
    WorkspaceWindow95(
      "Notes",
      icon: {
        Color.blue.frame(width: 16, height: 16)
      }
    ) {
      TextEditor95(text: .constant(""))
    }
    .menuBar95 {
      Menu95("File") {
        MenuItem95("New") {}
        MenuItem95("Open…") {}
        MenuDivider95()
        MenuItem95("Save As…") {}
        MenuDivider95()
        MenuItem95("Print", isEnabled: false) {}
      }
    }
  }
}
```

## Essential behavior

| Concern | Behavior |
| --- | --- |
| Placement | Add menus to [`WorkspaceWindow95`](/components/workspace-window/) with [`menuBar95`](/api/documentation/swift95/workspacewindow95/menubar95(content:)). |
| Content | Builders support items, dividers, conditions, and loops. |
| States | Items render enabled, highlighted, pressed, and disabled states. |
| Input | Supports pointer hover as well as touch press-and-drag selection. |
