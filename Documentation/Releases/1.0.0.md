# Swift95 1.0.0

Build interfaces from another timeline with a Windows 95-inspired component kit for SwiftUI.

Swift95 brings classic controls, desktop-style workspaces, themes and optional pixel icons to native Apple apps. Components work with SwiftUI bindings, environment values and accessibility behavior.

## Included

- Buttons, checkboxes, radio buttons, pickers, sliders, text inputs and editors.
- Lists, tabs, images, progress views, scroll containers and alerts.
- Desktop workspaces with windows, menus, shortcuts, a taskbar and Start menu.
- Theme tokens for colors, metrics, spacing, motion and fonts, with the bundled W95FA typeface.
- Optional `Swift95Icons` library.
- A component Catalog and three standalone examples: Spotify ’95, Slack ’95 and Finder ’95.
- [Getting started](https://swift95.dimasike.com/start/), [component guides](https://swift95.dimasike.com/components/) and [API documentation](https://swift95.dimasike.com/api/documentation/).

## Requirements

Swift 6, iOS and iPadOS 18 or later, or macOS 15 or later.

## Install

Add `https://github.com/DimaMishchenko/swift95` in Xcode's Package Dependencies and select version **1.0.0** or later. Add the `Swift95` product, and optionally `Swift95Icons`, to your target.

```swift
.package(url: "https://github.com/DimaMishchenko/swift95", from: "1.0.0")
```

```swift
import Swift95
import SwiftUI

struct ContentView: View {
  var body: some View {
    Button95("Hello, 1995") {}
  }
}
```

## Try the examples

Clone the repository, run `make generate`, and open `Swift95.xcworkspace`. Choose `Swift95Catalog`, `Spotify95`, `Slack95` or `Finder95`.

The example apps use local demo data. Music playback is simulated, chat messages stay in the app, and the file browser never accesses your real files. The examples are independent interface studies, unaffiliated with the services and apps that inspired them.
