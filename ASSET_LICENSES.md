## W95FA

Swift95 bundles `W95FA.otf`, a modern recreation of the Windows 95 interface typeface by Alina Sava / FontsArena.

- Original author page: https://fontsarena.com/w95fa-by-alina-sava/
- Author-published distribution profile: https://www.dafont.com/W95FA.font
- Embedded family / PostScript name: W95FA / `W95FARegular`
- SHA-256: `9e1ad53708307b2b68e06d43799b2267f6aec620dda972bc62753ad16ba50f2b`
- License: SIL Open Font License 1.1

The author describes W95FA as free for personal and commercial use under the SIL Open Font License. The OFL permits the unmodified font to be bundled and redistributed with software, provided the license accompanies it. Swift95 ships the license as `W95FA-OFL.txt` in the same resource bundle.

W95FA is an independent recreation; it is not Microsoft Sans Serif font software.
